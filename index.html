// 01. ABOUT

Architecting scalable, automated & resilient cloud systems

I am a Cloud Engineer & Cloud Architect focused on designing, deploying, and operating high-availability cloud infrastructure on Amazon Web Services (AWS).

My engineering foundation centers on automation, security, and scalability: converting architectural blueprints into modular, declarative Infrastructure as Code (Terraform), engineering multi-tier VPC network topologies, and enforcing least-privilege IAM security postures across environments.

With deep hands-on expertise in Linux systems administration, performance tuning, and structured production incident response, I build cloud systems that are resilient by design and backed by repeatable operational runbooks.
